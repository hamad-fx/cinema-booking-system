# Architecture and UML diagrams

This directory contains Mermaid source `.mmd` diagrams:

- `Use_Case.mmd` — Actors and main use cases (flowchart representation).
- `Class_Diagram.mmd` — UML-style domain classes and relationships.
- `Sequence_Booking.mmd` — Booking and double-seat-prevention sequence.
- `Activity_Booking.mmd` — End-user activity flow.
- `State_Booking.mmd` — Booking lifecycle.
- `ERD.mmd` — Database entity relationships.
- `Component_Architecture.mmd` — Frontend/backend component structure.
- `Deployment.mmd` — GitHub/CI/Render live deployment architecture.

You can preview Mermaid with a VS Code Mermaid extension or [Mermaid Live Editor](https://mermaid.live). During Phase 2, adapt labels/flows to actual code changes and ensure your instructor's exact lecture diagram conventions are satisfied. The use-case graph uses Mermaid flowchart notation, not strict UML use-case ellipses/tooling; redraw in draw.io/StarUML if strict UML notation is required.
