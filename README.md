# 🎬 CineVerse — Cinema Booking System

A functional university-team **full-stack demo** for booking movie tickets. **English user interface, Egyptian pound prices, sample movie data.**

## Run on your computer (VS Code terminal / PowerShell / Git Bash)

Install **Python 3.10+**. Open the project folder in VS Code: **File → Open Folder**. Open **Terminal → New Terminal** (or press Ctrl+`), then run:

```bash
python -m pip install -r requirements.txt
python server.py
```

On Windows if `python` is missing, use `py -m pip install -r requirements.txt` and `py server.py`.

Visit **http://localhost:8000/** in Chrome or Edge. Create a customer account under **Sign In → Create Account**. You can search films, choose a showtime, select seats, add snacks/promos, complete a **mock** purchase, view bookings and print a demo QR ticket.

**Admin login (optional):** Set `DEMO_ADMIN_EMAIL` and `DEMO_ADMIN_PASSWORD` as environment variables before starting. A minimum 12-character demo admin password is required. For Windows PowerShell:

```powershell
$env:DEMO_ADMIN_EMAIL="admin@your-team.example"
$env:DEMO_ADMIN_PASSWORD="use-a-unique-secret-password"
python server.py
```

For Git Bash/macOS/Linux:

```bash
export DEMO_ADMIN_EMAIL="admin@your-team.example"
export DEMO_ADMIN_PASSWORD="use-a-unique-secret-password"
python server.py
```

The Admin tab appears after logging in with that account. **Never commit real passwords or `.env` files.**

## What works

- Movie catalog, search, genre filters, movie detail pages, reviews and favorites.
- Movie, cinema hall, date and showtime selection.
- Live-on-refresh seat availability, VIP seats (+70 EGP), up to 8 seats per booking.
- Backend price calculation, snacks, promo codes (`CINE10`, `STUDENT15`). These are **demo codes**, not verified student eligibility.
- Account registration/login (hashed passwords, HttpOnly session cookies).
- Atomic SQLite bookings that prevent two accounts reserving the same seat on one showtime.
- Booking history, cancellation (before the day of the show), printable e-tickets and QR images.
- Admin-only catalog/showtime creation and demo revenue/booking analytics.
- CI tests, automated deploy hook, architectural diagrams and project-management templates.

**Intentionally not real:** card payments, refund transfers, email/SMS sending, cinema admission validation, and production capacity/scaling. QR codes encode a demo reference, not a real admission credential. The demo is not hardened or audited for financial transactions.

## Testing

```bash
python -m unittest discover -s tests -v
```

Tests run against a temporary SQLite database and exercise HTTP endpoints, authentication, bookings, seat conflicts, pricing, promos, reviews, cancellation and admin access.

## Important deployment constraint

This project uses SQLite. **Render free web services have an ephemeral filesystem; bookings can disappear whenever the instance restarts, redeploys, or spins down.** For a reliable deployed service, use a supported persistent disk or replace SQLite with a managed database such as PostgreSQL. See [deployment guide](docs/DEPLOYMENT.md). A public URL is **not** generated by the ZIP; the team must connect and deploy its own GitHub repository.

## Requirements

Python 3.10+; the only extra package is `qrcode[pil]` for QR generation. HTML, CSS and JavaScript run directly from the Python server. No NPM installation required.
